# Glossary

Names for things in this app. No implementation detail here.

## Layout on iPhone Duo

**Closed**: the Duo folded shut, using the outer display. The app looks and behaves as it does on any other iPhone: one screen at a time, tabs along the bottom.

**Open**: the Duo unfolded flat, using the inner display with the app full screen. The app shows a two-pane layout.

**Half-folded**: the Duo partly folded, with the fold dividing the inner display.

**Two-pane layout**: a list on the left and the selected item on the right, with the tabs in a sidebar. Shown when open. Not to be confused with Split View.

**Split View**: the system feature that puts two different apps side by side on the inner display. The app is then narrow and falls back to its closed layout.
